# Стратегии перевода технических терминов в субтитрах

29 сентября 2026

На основе анализа первых трёх фильмов корпуса (The Social Dilemma, AlphaGo, Coded Bias) выделила следующие стратегии:

## 1. Прямой эквивалент

Когда термин имеет устоявшийся перевод в русском:

| Английский | Русский | Пример из фильма |
|------------|---------|------------------|
| algorithm | алгоритм | «the algorithm recommends» → «алгоритм рекомендует» |
| data | данные | «big data» → «большие данные» |
| software | программное обеспечение / ПО | «open source software» → «ПО с открытым исходным кодом» |
| hardware | аппаратное обеспечение / «железо» | «hardware limitations» → «ограничения железа» |

**Частотность:** примерно 35% всех терминов в корпусе

**Проблемы:** некоторые «прямые» эквиваленты могут быть непонятны широкой аудитории (например, «аппаратное обеспечение» vs «железо»).

## 2. Описательный перевод

Когда прямого эквивалента нет или он слишком специфичен:

| Английский | Русский | Пример |
|------------|---------|--------|
| machine learning | машинное обучение | «machine learning models» → «модели машинного обучения» |
| neural network | нейронная сеть | «deep neural network» → «глубокая нейронная сеть» |
| cloud computing | облачные вычисления | «cloud computing services» → «сервисы облачных вычислений» |

**Частотность:** около 40% — самая частотная стратегия

**Проблемы:** длинные термины не всегда помещаются в 2 строки при ограничениях субтитров.

## 3. Транслитерация

Для международных терминов, которые уже вошли в русский:

| Английский | Русский | Пример |
|------------|---------|--------|
| blockchain | блокчейн | «blockchain technology» → «технология блокчейн» |
| startup | стартап | «tech startup» → «технологический стартап» |
| framework | фреймворк | «software framework» → «программный фреймворк» |

**Частотность:** около 15%

**Проблемы:** не все зрители знают эти термины, особенно старшая аудитория.

## 4. Генерализация

Замена конкретного термина на более общий:

| Английский | Русский | Пример |
|------------|---------|--------|
| actuator | привод / устройство | «the actuator moves» → «устройство двигается» |
| sensor array | датчики | «sensor array detects» → «датчики обнаруживают» |

**Частотность:** около 7%

**Проблемы:** потеря точности, но иногда необходимо из-за ограничений времени.

## 5. Опущение

Полное удаление термина, если он не критичен для смысла:

**Оригинал:** «The device uses an ARM Cortex-M4 microcontroller with 512KB flash memory.»
**Субтитры:** «Устройство использует микроконтроллер с памятью.»

**Частотность:** около 3%

**Проблемы:** риск потери важной технической информации.

---

## Выводы для диссертации

- Описательный перевод доминирует — это стоит отразить в результатах
- Прямые эквиваленты часто требуют проверки на понятность (опрос аудитории)
- Опущение используется редко, но в ключевых моментах может искажать смысл

# Репозиторий НИР: Исследование субтитров технической документалистики

**Тема:** Адаптация технической лексики в субтитрах документальных фильмов о технологиях (англо-русская языковая пара)

**Программа:** Теория и практика аудиовизуального перевода (магистратура)

**Дата начала:** 29 сентября 2025

---

## О проекте

Это рабочее хранилище Obsidian для магистерской диссертации. Здесь собираются:

- Конспекты источников (Gottlieb, Díaz Cintas и др.)
- Заметки по анализу корпуса фильмов
- Черновики глав и тезисов
- План работы и библиография

Структура папок соответствует методологии Zettelkasten / PARA, адаптированной под академическое исследование.

## Структура

| Папка | Назначение |
|-------|-----------|
| `00_Inbox` | Быстрые заметки, идеи, вопросы научруку |
| `01_Literature` | Конспекты статей и книг |
| `02_Notes` | Постоянные заметки (анализ, выводы, связи) |
| `03_Projects` | План диссертации, дедлайны, статусы |
| `04_Drafts` | Черновики глав, введения, разделов |
| `05_Output` | Готовые тезисы, статьи, доклады |
| `_Templates` | Шаблоны для анализа фильмов, опросов и т.д. |
| `_Attachments` | Таблицы, списки, библиография |
